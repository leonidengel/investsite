## Кратко о проекте

- **Что:** веб-дашборд инвест-портфеля (3 кошелька: 2 крипто + российские активы) + страница горячих пулов.
- **Стек:** Cloudflare Workers (бесплатный тариф) + KV + ванильный JS + GitHub Actions.
- **Ключевое ограничение:** 10 мс CPU/запрос и ~18.9 KB на ответ — из-за него вся архитектура (клиентский рендер, чанкинг, внешний синк пулов).
- **Деплой:** автоматический при пуше в `main` (GitHub Actions).

Подробно — в ARCHITECTURE.md.
